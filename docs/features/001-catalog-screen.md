- CORS включён в `main.ts` (`CORS_ORIGIN` через запятую, по умолчанию открыто): Mini App всегда живёт на другом origin, чем API.

## Найдено и починено попутно
- **Иконок не было вообще.** `Icon` дергал `window.lucide` из UMD-скрипта, которого нет в `index.html`, — все иконки рендерились пустыми `<span>`. Переписан на пакет `lucide-react` с поимённым реестром глифов (`components/icon/Icon.jsx`): `import { icons }` тянет весь набор Lucide и раздувал бандл до 1 008 КБ, реестр вернул его к 179 КБ (55,9 КБ gzip).
- **Vite не видел корневой `.env`** — `envDir: "../../"` в `vite.config.ts`. Без этого `VITE_API_URL` был бы `undefined`, и фронт молча стучался бы сам в себя.
- **`shared-types` собирается в CommonJS** (ради NestJS), поэтому первая же runtime-константа в нём (`CATALOG_SIZES`) сломала ESM-импорт из Vite — белый экран с `does not provide an export named`. Пакет вернули к чистым типам: размерная сетка теперь данные и приходит из API. Правило на будущее: **в `shared-types` только типы, никаких значений.**
- `ProductCard.d.ts` объявлял `sizes?: string`, хотя компонент рендерит туда произвольный узел (`Dot` + текст об остатке). Тип расширен до `React.ReactNode`.

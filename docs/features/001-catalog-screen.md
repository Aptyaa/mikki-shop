# 001 — Экран каталога

Статус: **in progress**

## Что сделано
- UI-кит на 34 компонента (`packages/ui`) сгенерирован навыком `mickey-shop-design` (палитра Butter, шрифт Bubblez Graffiti для wordmark), изначально лежал в корневом `src/` вне структуры монорепо — перенесён и интегрирован 2026-08-31.
- Экран `CatalogScreen` подключён как главный экран `apps/telegram-app` (`App.tsx`).
- Дизайн-токены (`packages/ui/src/styles`) подключены глобально через `@mikki-shop/ui/styles.css`.
- `pnpm --filter telegram-app build` (tsc + vite build) проходит чисто.

## Что исправлено при переносе
- `Logo.jsx`/`MascotBadge.jsx` использовали хак поиска `<script src="_ds_bundle.js">` для резолва пути к ассетам — работал только в standalone-превью дизайн-инструмента, в Vite не сработал бы. Заменено на обычный `import` ассетов (Vite сам резолвит путь и хэширует).
- `tokens/fonts.css` — неверный относительный путь до шрифтов (`../assets/` вместо `../../assets/`), шрифты не грузились бы (тихий 404).

## Не сделано
- Данные — статичные заглушки (`DEFAULT_PRODUCTS`/`DEFAULT_CATEGORIES` прямо в `CatalogScreen.jsx`), нет обращения к API.
- Компоненты каталога/корзины/карточки товара не типизированы полностью — есть готовые `.d.ts`, но т.к. импорты внутри UI-кита используют явное расширение `.jsx`, тайпчекер их не подхватывает (см. ARCHITECTURE.md, известное ограничение).
- `_adherence.oxlintrc.json` в корне — lint-контракт по пропсам/токенам от `mickey-shop-design`, не подключён ни к одному `lint`-скрипту, пути в правилах (`components/brand/**` и т.д.) не соответствуют новой структуре `packages/ui/src/components/**`. Нужно либо подключить и поправить пути, либо удалить.

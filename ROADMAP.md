Бот + Mini App: каталог товаров, карточка товара, корзина, оформление заказа без онлайн-оплаты (заявка менеджеру). Цель — быстро проверить спрос.

- [x] Каталог: сетка, категории, фильтры, поиск, пагинация — `docs/features/001-catalog-screen.md`, `003-catalog-pagination.md`
- [x] Карточка товара: размеры с остатками, таблица размеров, расцветки, похожие — `docs/features/006-product-screen.md`
- [x] Корзина на Zustand, пересчёт цен и наличия на бэкенде — `docs/features/007-cart.md`
- [x] Вход через `initData` Telegram, JWT, тёмная тема из клиента — `docs/features/008-telegram-auth.md`
- [x] Оформление заказа заявкой менеджеру: форма, заказы покупателя, списание остатков, согласие на обработку ПД — `docs/features/009-checkout.md`
- [x] Стартовый экран с онбордингом: витрина, «как это работает», категории, новинки — `docs/features/010-home-screen.md`
- [x] Кабинет покупателя и профиль питомца: порода, размер, мерки; кличка в заказе стала слепком — `docs/features/011-pet-profile.md`
- [ ] Бот: команды, `/start`. Уведомление менеджеру о заказе написано и уходит в Telegram, но живьём не проверялось — нужен `MANAGER_CHAT_ID` (см. `docs/features/009-checkout.md`)
- [ ] **Минимальный деплой** — блокер фазы: Mini App открывается только по публичному HTTPS, привязанному к боту. Лежал в фазе 6, но без него ни вход, ни заказ живьём не проверить, а цель фазы — проверить спрос.

## Фаза 7 — Социальная сеть для владельцев собак (опционально, зависит от спроса)
Использует Pet-профили и событийную шину, заложенные в архитектуре с самого начала:
- Лента/посты
- Поиск компаньонов для прогулок (геопоиск на PostGIS)
- Поиск для вязки
- Модуль Social/Matching подключается как отдельный сервис, не затрагивая код магазина

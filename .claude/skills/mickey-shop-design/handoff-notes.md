# Передача в разработку: дизайн-система «Микки Шоп»

Магазин одежды для маленьких собак, работающий как Telegram Mini App. Одна палитра
(Butter), 31 компонент, светлая и тёмная темы.

## Установка

Скачайте проект целиком (кнопка загрузки в чате), распакуйте и запустите:

```bash
cd /путь/до/вашего/проекта
bash /путь/до/mickey-shop/handoff/install.sh
# если исходники не в src:
# bash /путь/до/mickey-shop/handoff/install.sh . app
```

Скрипт раскладывает файлы так:

```
ваш-проект/
├── .claude/skills/mickey-shop-design/   SKILL.md, readme.md, заметки по компонентам,
│                                        карточки-специмены
├── _adherence.oxlintrc.json             правила линтера
└── src/
    ├── styles/styles.css + tokens/      один import — и все токены на месте
    ├── components/ui/<группа>/          31 компонент: .jsx + .d.ts
    └── assets/                          маскот + шрифты Bubblez Graffiti
```

Дальше два шага вручную — они зависят от вашей сборки:

1. `import "./styles/styles.css";` в точке входа приложения.
2. `npx oxlint --config _adherence.oxlintrc.json src/` — добавьте в CI. Это единственная
   защита от того, что кто-то напишет `#F9DC5C` вместо `var(--action-primary)`.

## Что где лежит

**`components/`** — production-код. Обычный React, зависимости только `react` и
`lucide-react` (иконки). Импорты внутри компонентов относительные (`../core/Tag.jsx`),
поэтому структуру групп `brand / icon / core / forms / commerce / navigation / feedback`
менять нельзя. Рядом с каждым компонентом лежит `.prompt.md`: когда применять, когда не
применять, что было отвергнуто и почему.

**`ui_kits/telegram/index.html`** — **дизайн-референс, не production-код.** Клик-прототип
Mini App, 9 экранов: онбординг, главная, каталог, товар, подбор размера, корзина,
оформление, профиль питомца, заказы. Открывается в браузере как есть; рельса сверху —
переход между экранами и переключатель тёмной темы. Экраны нужно **воспроизвести** в вашей
среде, а не копировать HTML.

**`guidelines/*.html`** — карточки-специмены: цвет, типографика, отступы, тени, motion,
брендовые компоновки, фотобрифинг.

## Точность

**High-fidelity.** Цвета, типографика, отступы и радиусы финальные и заданы токенами —
воспроизводить попиксельно. Не финальны только **фотографии товара**: их не существует,
место держит компонент `PhotoSlot`. Брифинг — `guidelines/brand-photography.html`.

## Принципы, которые нельзя потерять при переносе

Полностью — в `readme.md`. Кратко:

- **Одна палитра, Butter.** Однотонная жёлтая рампа (Cornsilk `#FDF8E1` → Naples yellow
  `#F9DC5C`) плюс оливковые чернила `#2A2510`. Единственный чужой оттенок — danger
  `#B8402A`. Атрибута `data-palette` нет: альтернативы были инструментом выбора и удалены.
- **Только семантические алиасы.** Компоненты обращаются к `--action-primary`,
  `--surface-card`, `--text-heading` и ролям `--nav-active`, `--accent-fav`,
  `--rating-star` — никогда к значениям рамп. Это и проверяет линтер.
- **Бумага, а не пластик.** Радиусы 2–6px, хайрлайны вместо рамок, жёлтые полосы от края
  до края вместо тонированных панелей. `--sh-card: none` — тень только у того, что реально
  висит над контентом: шиты, поповеры, кнопки поверх фото.
- **Тёмная тема обязательна.** Telegram Mini App наследует тему пользователя,
  `[data-theme="dark"]` — не опция. Это единственная многовариантность в системе.
- **Сетка товаров.** `ProductCard` — основная раскладка каталога: две плитки в ряд на
  390pt, без рамки, плитка — это фотография. `ProductRow` остался для корзины и
  сохранённого, где размер читается рядом с ценой.

## Проверка после установки

1. `var(--action-primary)` в девтулзах = `#FAE588` → стили подключены.
2. Вордмарк «Микки Шоп» рисуется Bubblez Graffiti → `.otf` найдены. Пути лежат в
   `styles/tokens/fonts.css` относительно `styles.css`; при другой структуре правьте
   только этот файл.
3. `data-theme="dark"` на корне перекрашивает интерфейс → тёмная тема жива.
4. `npx oxlint --config _adherence.oxlintrc.json src/` проходит без ошибок.

## Первый промпт в Claude Code

> Прочитай `.claude/skills/mickey-shop-design/SKILL.md` и `readme.md`. Собери экран
> каталога на компонентах из `src/components/ui`. Используй только семантические токены;
> не добавляй тени, скругления больше 6px и вторые оттенки — палитра однотонная.

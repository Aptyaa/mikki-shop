Square-cut label. Sits on a photograph like a stamped price ticket — sharp corners, uppercase, 11px.

```jsx
<Tag tone="paper">−30%</Tag>
<Tag tone="new">новинка</Tag>
```

`paper` is the default choice on imagery: the page colour, so the label reads as printed on rather than
stuck on. Reserve `sale` and `new` for the one thing on a screen that must be loud. **One tag per product.**

Tags are the only square-cornered small element left after the paper direction — and now everything around
them is square too, so they no longer stand out for the wrong reason.

Quiet signal dot. Prefix a meta line with it when that line is the reason to look.

```jsx
<span><Dot/>меринос · XS–M · осталось 4</span>
```

**Intentional addition.** It replaces a second and third coloured badge: in a one-hue palette, three tag
colours are not available, so emphasis is carried by a dot plus word order instead. Never more than one dot
per row, never two rows in a row.
